# inHOMEuse

Онлайн-аренда квартир без личных встреч. Заявка, чат, оплата Kaspi и код от замка — внутри одного приложения.

Рынок старта: Казахстан (Алматы, Астана, Шымкент). Языки: қазақша, русский, English.

## Что умеет

- Поиск квартир с фильтрами и картой
- Заявка жестом «ключ в замок»
- Чат арендатора и владельца
- Демо-оплата Kaspi (QR, референс, код smart-lock)
- Объявления хозяина, избранное, отзывы, профиль
- Вход: email и пароль, Google, X

## Стек

TanStack Start, React 19, Tailwind v4, Postgres (Neon в проде, PGLite без настройки), Better Auth.

## Бесплатный хостинг

Деньги на старте не нужны.

**Вариант А. Публикация из Grok**  
Кнопка публикации в этом чате поднимает приложение на бесплатный адрес и сама подставляет базу и вход через Google/X. Свой домен можно привязать позже.

**Вариант Б. Свой GitHub + Vercel + Neon, всё по 0 USD**

1. Репозиторий: [K09-0/inHOmeUSE](https://github.com/K09-0/inHOmeUSE).
2. [Neon](https://neon.tech) — бесплатный Postgres, скопируйте `DATABASE_URL`.
3. [Vercel](https://vercel.com/new) — Import `K09-0/inHOmeUSE`. Команда сборки: `npm run build`. В Environment Variables добавьте `DATABASE_URL`.
4. Адрес будет вида `https://inhomeuse.vercel.app`. Свой домен — около 10–15 USD в год, когда появится бюджет.

Магазины: Google Play Console — разовый платёж 25 USD. App Store — 99 USD в год. До этого приложение ставится как PWA с телефона.

## Kaspi Pay

В приложении встроен демо-поток: QR, референс `KSP-…`, подтверждение, выдача кода замка. Деньги не списываются.

Боевой режим после регистрации в Kaspi Business:

- токен мерчанта в заголовке `Authorization: Bearer …`
- `POST /payments/create` — сумма, описание, `redirect_url`
- `GET /payments/status` — статус платежа
- перевод владельцу после холда

PCI остаётся на стороне Kaspi. В коде точка замены — `confirmKaspiPayment`.

## Локально

```bash
npm install
npm run dev
```

Без `DATABASE_URL` поднимается встроенный Postgres. Схема и демо-квартиры Алматы, Астаны и Шымкента применяются сами.
